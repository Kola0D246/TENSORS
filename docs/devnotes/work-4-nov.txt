1. Core Backend Architecture

Designed and scaffolded a modular Django backend under backend/apps/ with four key apps:
apps/
 ┣ institutes/  → Institute, Department, Course, Subject, Faculty, Student
 ┣ scheduler/   → TimeSlot, Infra, FacultyUnavailability, Occupancy
 ┣ users/       → User model with role-based access (Admin, HOD, Faculty, Student)
 ┗ api/         → REST API layer (Django REST Framework)


Each app has:

models.py for database schema
serializers.py (to be extended)
views.py with DRF ViewSets
urls.py connected via a global router
